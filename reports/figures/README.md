# Selected scientific figures

This directory retains a small set of overview and result figures. The notebooks
and `scripts/generate_*` commands produce additional diagnostics during local
execution. Filenames remain stable so code and figure references agree.

| Figure | Content |
|---|---|
| `arquitectura_dos_canales.png` | Acquisition policy and oracle-label routing |
| `representacion_fotometrica_304.png` | Composition of the 304-feature representation |
| `gp2d_superficie_ejemplo.png` | Illustrative joint GP interpolation |
| `fig_batch_vs_escala.png` | Single-batch and combined-pool comparison |
| `mecanismo_saturacion_presupuesto.png` | Confidence-triage saturation diagnostic |
| `10_train_vs_test_mf1.png` | Calibrated OOF versus external batch-4 evaluation |

These figures describe simulated complete-light-curve experiments. They should
be read with the evaluation definitions and limitations in the reproduction guide.
